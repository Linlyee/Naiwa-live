## 🚀 快速启动与使用

### 第一步：打开直播间页面（预览与调试）
在终端中运行：
```powershell
python douyin_live/start_live_preview.py
```
- 浏览器会自动打开 `http://localhost:8088/index.html`。
- 页面右下角贴心地内置了 **【⚙️ 导演台】**，点击即可随时一键测试弹跳、吹泡泡、压扁成荷包蛋、爱心雨、金币雨等全部效果！

### 第二步：配置到 OBS / 抖音直播伴侣
1. 打开 OBS 或抖音直播伴侣，将画面模式设为 **竖屏（1080 × 1920）**；
2. 在来源列表中点击 `+`，选择 **【浏览器】(Browser)**；
3. 参数设置：
   - **URL**：`http://localhost:8088/index.html`
   - **宽度**：`1080`
   - **高度**：`1920`
   - **帧率**：`60`
4. 勾选“当源变为可见时刷新浏览器”。即可直接看到高清晰、无任何黑边/白边的专属定制直播间！

### 第三步：联动 Open-LLM-VTuber 语音与大脑
1. 在另一个终端启动项目主服务：
   ```powershell
   uv run run_server.py
   ```
2. 页面会自动通过 WebSocket（`localhost:12393`）建立连接。当 AI 生成语音和台词时，小黄人会自动根据节奏同步张合嘴型并刷新悬浮台词！
