## 一、 项目深度介绍与架构解析

### 1. 为什么做这个项目？解决什么痛点？
传统的无人直播通常采用固定视频循环播放，观众发送弹幕毫无反馈，容易被抖音平台判定为低质录播而遭受限流甚至封禁；而传统 Live2D 虚拟主播配置门槛高、模型笨重、无法做到精准匹配抖音常驻礼物的视觉与专属声优级语音互动。

**Naiwa-live** 应运而生，专为解决以下痛点而设计：
1. **真实互动防限流**：每条观众弹幕、点赞、进房与送礼都会在毫秒级触发角色的物理动作反馈与实时大模型对答，杜绝平台录播判定。
2. **极高转化与打赏激励**：设计了「受击压扁荷包蛋」、「贪吃充气变大圆球」、「小心心喷泉」、「啤酒微醺」、「金币暴击瀑布」等爆笑声画效果，极大刺激直播间观众送礼互动欲望。
3. **粉丝粘性与点歌留存**：内置互动点歌台，观众弹幕点歌自动排队，送礼享有 VIP 皇冠顶歌特权，拉长观众停留时长。
4. **轻量免显卡纯前端**：无需复杂的 3D 渲染器与昂贵显卡，纯矢量分层与 CSS3 物理动效即可在普通笔记本上跑满 60 帧 1080×1920 高清画质。

### 2. 系统底层技术架构与运作原理

整个系统的数据与控制链路如下图所示：

```
┌─────────────────┐       WebSocket       ┌────────────────────────┐
│  抖音直播间观众   │ ───────────────────> │ 抖音弹幕抓手           │
│  (弹幕/点赞/送礼)│                      │ (BarrageGrab 监听引擎)  │
└─────────────────┘                      └───────────┬────────────┘
                                                     │ HTTP / WebPush (12393)
                                                     ▼
┌──────────────────────────┐  WebSocket   ┌────────────────────────┐
│ 1080×1920 竖屏互动前端   │ <─────────── │ 本地事件分发中枢       │
│ (CSS3物理动效+歌单+粒子)  │ (8088 端口)  │ (live_bridge_server.py)│
└────────────┬─────────────┘              └───────────┬────────────┘
             │                                        │
             │ 音频分流                                │ 大模型对话请求
             ▼                                        ▼
┌──────────────────────────┐              ┌────────────────────────┐
│ 虚拟声卡 (VB-Audio Cable) │              │ 大模型与语音合成引擎   │
│ 干净推流至【抖音直播伴侣】 │              │ (Local LLM / CosyVoice)│
└──────────────────────────┘              └────────────────────────┘
```

1. **弹幕捕获层**：基于 `BarrageGrab` 引擎无感监听抖音官方直播推流通道，捕获弹幕发言、小心心/啤酒/礼物打赏、进房欢迎及点赞数据；
2. **事件路由中枢 (`live_bridge_server.py`)**：负责礼物别名归一化、去重、节流防刷、意图识别与大模型智能对话生成；
3. **动态渲染前端 (`index.html`)**：通过高频 WebSocket 接收动作指令，驱动角色分层骨骼做非线性物理回弹、触发全屏 Canvas 粒子暴击与音效播报；
4. **音频流控层**：将背景音乐、礼物原声音效和 TTS 语音无缝混流送入独立虚拟声卡，实现与主播电脑其他杂音的物理级隔离。

### 3. 五大核心模块与功能特色

1. **纯矢量拟真动态角色引擎 (Flawless Rig)**：
   - 针对 1080×1920 竖屏量身打造，支持原生透明背景；
   - 具备呼吸起伏、灵动眨眼、自然 Lip-sync 张嘴说话、心动害羞红晕、受力压扁成荷包蛋、充气膨胀成大圆球、肚皮律动大笑等丰富的仿生动作。
2. **实时大模型智能应答系统**：
   - 支持接入本地 LLM 或云端高性能大模型，赋予角色机智、幽默、呆萌的个性，秒级对观众弹幕展开自然聊天。
3. **高保真礼物声画联动与母带原声**：
   - 告别单调文字提示，为每种主流礼物定制专属的全屏视觉粒子特效与录音棚母带级声优配音，即送即播。
4. **VIP 互动点歌台与 DJ 智能串场**：
   - 观众弹幕点歌实时进入排队队列；
   - 赠送专属礼物即可激活 VIP 皇冠插队置顶特权；
   - 队列空闲时系统自动进入 DJ 伴奏串场模式，绝不出现冷场空白。
5. **硬件级双通道音频隔离方案**：
   - 直播间只输出角色声音与伴奏，主播自己在电脑上看电影、玩游戏、开麦聊天的声音完全不会泄露进直播间。

## 三、 手把手完整使用流程指南 (保姆级)

为确保你能一次配置成功并顺利开播，请严格按照以下步骤操作：

```
[步骤1：环境准备] ──> [步骤2：音频隔离设置] ──> [步骤3：填写直播间号] ──> [步骤4：一键启动] ──> [步骤5：直播伴侣推流]
```

### 第 1 步：基础环境与运行依赖准备
1. 确保电脑已安装 **Python 3.10 或更高版本**（安装时务必勾选 `Add Python to PATH`）。
2. 下载并安装虚拟音频驱动 **VB-Audio Virtual Cable**（官方免费）：
   - 安装完成后，你的电脑声音设备中会出现名为 `CABLE Input` 和 `CABLE Output` 的音频设备。
3. （初次使用弹幕抓手必看）打开 `barrage_grab/` 目录，双击运行：
   ```
   barrage_grab\1_安装微软运行环境(仅初次需要).bat
   ```
   这将自动安装抓手运行所需的 .NET 8.0 运行时环境。

---

### 第 2 步：音频隔离配置（杜绝杂音流进直播间）
为了保证直播间内**只有主播虚拟人的声音和音乐伴奏**，而没有你电脑自身的微信提示音、游戏背景声，需配置音频隔离：

1. 双击运行项目根目录的：
   ```
   【一键设置音频监听】.bat
   ```
   （此脚本会自动为你打开 Windows 声音录制控制面板）。
2. 在弹出的声音面板中：
   - 切换到 **【录制】** 标签页；
   - 找到 **【CABLE Output】**，鼠标双击打开其属性；
   - 点击 **【侦听】** 标签页；
   - 勾选 **【侦听此设备】**；
   - 在“通过此设备播放”下拉列表中，选择你平时戴的 **【耳机】**；
   - 点击 **【确定】** 保存。
3. **效果说明**：
   - 这样设置后，虚拟人说话和伴奏会分流进你的耳机让你听见；
   - 但你电脑自身的微信消息、游戏声音依然走原耳机声道，完全不会流进直播推流声道！

---

### 第 3 步：配置抖音直播间参数与 API 密钥
1. 打开 `barrage_grab/` 文件夹：
   - 复制 `config.json.template` 并粘贴重命名为 `config.json`；
   - 使用记事本或编辑器打开 `config.json`，找到：
     ```json
     "Platforms": {
       "Douyin": {
         "Enabled": true,
         "RoomId": "YOUR_DOUYIN_ROOM_ID"
       }
     }
     ```
   - 将 `YOUR_DOUYIN_ROOM_ID` 修改为你开播后的真实抖音直播间 ID 或直播分享长链接，保存文件。
2. （可选）大模型与 TTS 密钥配置：
   - 本系统默认采用环境变量方式读取密钥，避免源码泄露：
     ```powershell
     # 在开播终端中或系统环境变量中设置：
     set SILICONFLOW_API_KEY=你的硅基流动API密钥
     ```

---

### 第 4 步：一键全系统启动
在项目根目录下，双击运行核心控制脚本：
```
【一键启动直播】.bat
```
脚本将按顺序全自动执行以下动作：
1. **自动拉起后端中枢网关**（`live_bridge_server.py`，端口 12393）；
2. **自动拉起静态 Web 服务**（`start_live_preview.py`，端口 8088）；
3. **自动调起弹幕抓手控制台**（开始实时捕获直播间互动）；
4. **以独立应用窗口模式打开竖屏直播间**（记忆上一次的窗口位置与尺寸）。

> 💡 **提示**：启动后弹出的控制台窗口请保持后台最小化运行，不要手动关闭。

---

### 第 5 步：抖音直播伴侣推流设置
1. 打开并登录 **【抖音直播伴侣】**；
2. 在场景画面下方，点击 **【添加素材】** -> 选择 **【窗口】**；
3. 在窗口列表中选择名为 **`奶娃AI直播`** 或 `http://localhost:8088/index.html` 的独立窗口；
4. 画面分辨率推荐设置为竖屏标准的 **1080×1920**，并将其铺满推流画布；
5. **配置推声音频**：
   - 在直播伴侣右下角的音频设置中；
   - 将麦克风/音频输入设备选择为 **【CABLE Output (VB-Audio Virtual Cable)】**；
   - 将电脑其他无关麦克风静音，即可实现 100% 纯净无杂音推流！

---

### 第 6 步：伴奏与点歌联动操作
1. 双击根目录的 `【打开QQ音乐网页版】.bat`；
2. 登录你的音乐账号（登录态会自动持久化记忆在本地专属配置中，无需重复扫码）；
3. 当观众在直播间发送 `点歌 歌名` 时，你可以在该窗口中即搜即播，声音将经由音频流控直接无损流入直播间！

## 五、 常见问题与故障排查 (FAQ)

### Q1：为什么观众在直播间发弹幕，虚拟人没有任何反应？
1. 检查 `barrage_grab/config.json` 里的 `RoomId` 是否填成了你当前的开播间 ID；
2. 检查抓手黑色控制台窗口中是否有滚动显示观众的发言；
3. 若提示抓手未连接，请在开播后重新运行 `启动抖音弹幕抓手.bat`。

### Q2：为什么我的耳机能听到角色说话，但直播间观众听不到？
- 请检查【抖音直播伴侣】的音频输入设置，必须将音频输入/麦克风设备指定为 **`CABLE Output`**，而不是电脑自带麦克风。

### Q3：为什么直播间里会有我打游戏或微信聊天的杂音？
- 说明你电脑的默认播放设备被设成了 `CABLE Input`。
- 正确做法：电脑系统默认声音播放设备请选你的【扬声器/耳机】，只让直播独立窗口或音乐软件走 `CABLE Input`。

### Q4：画板窗口加载较慢或提示没有声音自动播放权限？
- 本项目自带的 `【一键启动直播】.bat` 已自动注入 `--autoplay-policy=no-user-gesture-required` 参数，请务必通过批处理脚本启动，不要直接用常规浏览器双击打开 html 文件。

为确保本项目的代码安全与个人隐私隔离，开发及版本控制中严格遵循以下准则：
