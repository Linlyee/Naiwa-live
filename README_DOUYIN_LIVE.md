# 抖音 AI 拟真互动直播系统 (Douyin AI Live VTuber)

> 基于 **Open-LLM-VTuber** 深度定制开发的**抖音 9:16 高拟真 AI 虚拟主播互动直播间解决方案**。  
> 集成「3D/SVG 拟真动态形象 + 实时弹幕智能互动 + 礼物连击特效 + VIP 互动点歌台 + 离线原声声优配音 + 自动化直播推流配套」。

---

## 🌟 核心功能特色

### 1. 纯前端拟真动态角色引擎 (Flawless Rig Engine)
- **1080×1920 高清竖屏适配**：专为抖音、快手等竖屏直播平台优化，支持透明通道。
- **高拟真动画**：采用矢量分层与平滑物理缓动算法，支持待机呼吸微动、无辜眨眼、说话自然唇形同步（Lip-sync）、开心高弹跳（Boing）、心动害羞红晕、受击压扁荷包蛋、贪吃充气变圆球、肚皮大笑等丰富拟态。

### 2. 实时弹幕与事件智能感知 (Live Bridge System)
- **全自动弹幕监听**：内置高性能 WebSocket 桥接服务，无缝接入主流抖音弹幕抓手工具。
- **弹幕大模型智能对答**：支持本地 LLM、SiliconFlow、Gemini 等大模型引擎，自动过滤脏话，智能解析观众意图并结合人设进行幽默语音回答。
- **自动欢迎与点赞答谢**：观众进房自动打招呼、点赞飘屏反馈，提升直播间留存率。

### 3. 沉浸式礼物打赏与声画联动
- **全屏粒子特效**：小心心粉色喷泉、啤酒微醺摇摆、玫瑰花甜蜜飞吻、满屏金币瀑布大轰炸。
- **原声音效与专属台词**：针对主流常驻礼物深度定制高保真原声音效与声优台词，即送即响，绝无延迟。

### 4. 互动歌单与 VIP 智能点歌台
- **弹幕点歌**：观众发送 `点歌 歌曲名`，系统自动识别并加入右侧动态悬浮歌单排队。
- **VIP 送礼插队**：粉丝赠送指定礼物（如啤酒/玫瑰/小心心）触发 **VIP 顶歌** 机制，皇冠置顶并播报专属特权台词。
- **DJ 智能串场**：空闲时自动循环播放高品质 BGM 伴奏，永不冷场。

## 🚀 快速上手与运行指南

### 第一步：准备运行环境
1. 确保安装了 **Python 3.10+**。
2. 推荐安装虚拟音频驱动（例如 **VB-Audio Cable**），便于将 AI 发出的声音与背景音乐独立推送到【抖音直播伴侣】。
3. （可选）安装微软运行库：若需要运行弹幕抓手，首次使用请运行 `barrage_grab/1_安装微软运行环境(仅初次需要).bat`。

### 第二步：配置环境与密钥（安全第一）
1. **弹幕抓手配置**：
   - 复制 `barrage_grab/config.json.template` 为 `barrage_grab/config.json`。
   - 打开编辑，将 `"RoomId": "YOUR_DOUYIN_ROOM_ID"` 修改为你自己抖音开播后的真实直播间号或长链接。
2. **大模型 / TTS 密钥配置（可选）**：
   - 本系统默认读取环境变量，避免密钥硬编码：
     ```powershell
     $env:SILICONFLOW_API_KEY="你的硅基流动API密钥"
     $env:ANTIGRAVITY_API_KEY="你的本地API密钥"
     ```

### 第三步：一键开播
1. **双击运行 `【一键启动直播】.bat`**：
   - 会自动启动后端的 `live_bridge_server.py` 服务，并自动在独立窗口中打开 `http://127.0.0.1:8088/index.html`。
2. **双击运行 `启动抖音弹幕抓手.bat`**：
   - 抓手会自动监听你设置的直播间，实时捕获评论、点赞、送礼，并推送给直播间页面做出互动。
3. **在【抖音直播伴侣】中推流**：
   - 添加素材 -> 选择「窗口」-> 选择打开的 `抖音 AI 互动直播间` 窗口。
   - 画面选择 1080×1920，即可完美全屏展示！

## 🔒 隐私与开源安全规范

为了保护你的个人隐私和账号资产安全，本项目默认配置了极其严格的 `.gitignore` 规则：
- **Edge 浏览器配置 (`edge_profile/`)**：绝对不纳入版本库，防止真实 Cookies、密码等泄露。
- **敏感 Cookie 提取脚本 (`*cookies*.py`)**：已被列入忽略。
- **真实直播间配置 (`barrage_grab/config.json`)**：不纳入版本库，仅提供模板。
- **本地测试音频与录屏大文件 (`*.mp4`, `*.webm`, `*.bin`, `test_*.wav`)**：已被全量忽略，防止仓库臃肿超限。
- **API 密钥**：全部已改用环境变量读取，杜绝硬编码泄漏风险。
